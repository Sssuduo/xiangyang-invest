## 一、项目是什么

襄阳国家农高区招商服务平台，服务于农高区招商专班：
- **业务端**（前台）：招商宣传、项目库展示、数据看板、AI 工具箱
- **管理端**（后台）：所有数据 CRUD、导入导出、权限管理

**技术栈**：
| 层 | 技术 |
|---|---|
| 前端 | Vue 3 (Composition API) + Element Plus + Vite + ECharts |
| 后端 | Flask + SQLAlchemy + SQLite（WAL） |
| 部署 | 阿里云 123.56.9.243，gunicorn (`--preload -w 2 -b 127.0.0.1:8000 --timeout 600`) + nginx，systemd 服务 `invest-app` |
| LLM | 通过 `services/llm_service.py` 统一调用（deepseek 系列等，模型配置存 DB `llm_models` 表） |

## 二、Git 与部署流程（必读）

**分支策略**（有 pre-push/pre-commit hook 强制）：
- `dev`：开发测试分支，所有修改先提交到这里
- `master`：生产分支，**受保护**，只接受 `git merge --no-ff dev` 合入

**标准流程**：
```bash
# 在 dev 提交
git checkout dev && git add ... && git commit -m "..."
git push origin dev
git checkout master && git merge --no-ff dev -m "Merge dev: ..."
git push origin master
# 部署生产
ssh -i "/c/Users/苏铎/.ssh/id_ed25519_new" root@123.56.9.243 "cd /www/wwwroot/invest-app && bash deploy.sh master"
```

**部署关键认知**（踩过的坑）：
1. **deploy.sh 双路径**：git 跟踪的是 `scripts/deploy.sh`（有 `--exclude='data'` 保护 + 受保护资产断言）；生产根目录 `deploy.sh` 是 **untracked** 的实际执行入口。两者必须同步（`cp scripts/deploy.sh deploy.sh`），否则地图数据被 `rsync --delete` 清空。
2. **`static/data/`**：地图 JSON（china_provinces/hubei_cities/china_cities），git 跟踪但不在 dist 里，deploy.sh 有兜底备份+断言恢复。
3. **`static/uploads`**：用户上传文件，物理目录 `backend/static/uploads`，**部署绝不能删**。正式备份用 `tar czf backups/uploads_backup_$(date).tar.gz -C /www/wwwroot/invest-app backend/static/uploads`（勿 tar 软链，会漏文件）。
4. **前端构建缓存陷阱**：改动不生效时 `rm -rf node_modules/.vite node_modules/.vite-temp dist && npm run build`。
5. **nginx 改动**需 `nginx -s stop && nginx` 全杀 worker，仅 reload 会间歇 404。
6. **后端改动后直接重启**：`systemctl restart invest-app`（用户已授权自动重启）。
7. **数据库迁移**：`backend/app.py` 的 `_run_auto_migrations()` 自动补列（MIGRATIONS 字典按表声明缺失列），新字段加那里即可。

### 3.1 业务域模块
| 模块 | 前端入口 | 后端路由 | 说明 |
|---|---|---|---|
| 招商项目库 | `/investment` | `admin_investment.py` | 核心数据，含诉求子表、标签、专班研判结论 |

| 工作台账管理 | `/investment-activity-ledger`（一级菜单） | `admin_activity_ledger.py` + `admin_activity_ledger_audio.py` | 台账可关联招商项目（写动态）或**在建项目（写工作进展）**；录音三版本总结（分段原文/清洁版/摘要版） |
| 在建项目库 | `/construction` | `admin_construction.py` | 含工作进展/调度问题/工作路径图 |
| 企业诉求 | 项目内 | `admin_demand.py` | 二级字典、状态流转 |

| 首页轮播图册 | `/` `/intro` | `api.py::/upload` | 18+ 张轮播图，DB `carousel_pages` |

### 3.2 消息提醒系统（V16.21-22 重构）
- **规则**：`message_rules` 表，2 条正式规则（超期 14 天未研判 / 超期 14 天无动态），全部用户
- **引擎**：`services/message_engine.py`，APScheduler 每天 09:00 跑；**先清空待处理再写入**，已处理（done）保留；`get_triggered_projects()` 供消息+看板复用
- **消息站**：顶栏铃铛抽屉，角标 = 待处理数量（打开不清零）；三 Tab（待处理/已挂起/已处理）各带数量；同项目同规则去重；**协同处理**——任一用户处理某项目，其他用户该消息移入已处理并显示处理人/时间
- **看板超期表格**：拆 2 表（未研判/无动态）各 10 行分页，表头悬停显示规则逻辑，表头旁显示规则运行时间

### 3.3 公文写作（V16.25 双模式）
入口 `/official-doc`（AI 工具箱二级菜单最下方）
- **模式 A 从零创作**：三步（素材→提纲→成文），Skill 规则注入（V+N/N+V、按拿推、六大逻辑）
- **模式 B 框架复用**：**旧材料换数据**场景。上传范本→LLM 解析骨架（`services/official_doc_skeleton.py`，标注 `fixed` 定型段/`slot` 槽位段+槽位语义）→前端骨架可视化编辑→槽位数据映射（可一键从招商项目导入自动匹配）→逐段生成（fixed 保留原文、slot 用新数据替换）。LLM 失败回退正则+本地拼装

### 3.4 录音识别/总结（ASR）
- **链路**：笔记本本地 ASR（端口 5002，SenseVoice ONNX，GPU 模式 `ASR_DEVICE_ID=0`）→ SSH 反向隧道 → 服务器 15002 → 后端 `speech_to_text.py`
- **看门狗**：`scripts/asr_watchdog.ps1`（30 分钟循环）+ **守卫** `scripts/asr_watchdog_guard.ps1`（15 分钟心跳自检，心跳过期自动重启看门狗，全 ASCII 日志避免 PS5.1 UTF-8 解析坑）
- **已知故障模式**：隧道"僵死"（进程在但 Send-Q 积压数据不转发）、waitress 线程池僵死、gunicorn 坏连接池。快速诊断：`curl http://127.0.0.1:15002/health`（>1s 即异常）+ `ss -tnp | grep 15002` 看 Send-Q
- **三阶段总结**：`services/text_summarizer.py`（规则分段→清洁版→摘要版），与 PDF 导出解耦

### 3.5 PDF 导出（工作台账录音总结）
- `services/pdf_service.py`：GB/T 9704-2012 公文格式（小标宋二号标题/黑体段落标题/仿宋正文/29磅行距）
- 内容有 `#` 标题则提取为 PDF 标题，否则 `[录音总结]`；圆点转 1.2.3. 序号每段重排
- 公文清洗（official_clean_service）已**屏蔽**，直接基于原始内容排版

### 3.6 权限

## 六、常见坑速查

1. **列表接口 500 前端空列表**：检查 `joinedload` 引用的 relationship 是否存在于模型（曾发生 `InvestmentLead.ai_model` 缺失）
2. **SQLAlchemy `hasattr(Class, 'col')` 陷阱**：类属性访问抛异常而非返回 False，判断列是否存在要用 `inspect`
3. **日期类型混算**：DateTime 列与 `date.today()` 相减报 TypeError，先 `.date()`
4. **地图 404**：`static/data` 被部署清空，从 `backups/static_data_deploy_*` 恢复 + 确认根目录 deploy.sh 含 `--exclude='data'`
5. **图片 404**：webp 自动转换但文件未生成 → `toWebpUrl` 已加探测回退；uploads 物理丢失 → 从 `backups/uploads_backup_*` 恢复
6. **ASR 转写卡"准备中"**：依次查隧道 health 延迟（>1s 异常）、Send-Q 积压（僵死隧道）、waitress 线程池、gunicorn 连接池；重启顺序：ASR 服务→隧道→gunicorn
7. **外键约束**：删 message_rules 会被 user_messages 引用挡住，用停用（is_active=False）代替删除
8. **PowerShell 5.1 + UTF-8 中文脚本**：解析报错，日志/字符串用 ASCII
9. **Shell 工作目录漂移**：bash 会话 cd 后不自动回项目根，git 操作前确认 `pwd`
